# TDFG Data Factory v1.2.0

Отдельное приложение для генерации и обслуживания тестовых клиентов TDFG.

## Главное изменение v1.2.0

Полный цикл теперь сделан как мастер создания клиента:

1. Нажми **Сгенерировать данные**.
2. Проверь ФИО, дату рождения, паспорт, ИНН и телефоны.
3. При необходимости поправь любое поле руками.
4. Выбери пакет услуг и, если нужно, закрепление в КО.
5. Нажми **Показать весь сценарий** или **Запустить полный цикл**.

Данные больше не являются “слепыми”: перед отправкой их видно в UI.

## Что умеет

### 1. Мастер создания клиента

- генерация ФИО;
- генерация даты рождения;
- генерация паспорта;
- генерация ИНН;
- генерация телефонов;
- ручное редактирование всех сгенерированных полей;
- выбор ПУ: `PRIME2`, `PRIVILEGE2`, `MULTICARTA`, либо без ПУ;
- опциональное закрепление клиента в КО;
- предпросмотр полного сценария;
- итоговая карточка клиента в живом логе.

### 2. Подключить только ПУ

- вводишь MDM ID;
- выбираешь пакет услуг;
- смотришь тело запроса;
- выполняешь только шаг `set_package`.

### 3. Подключить клиента в КО

- вводишь MDM ID;
- вводишь логин сотрудника;
- вводишь `newPackageName`;
- при необходимости вводишь точку продаж / `pointOfSale`;
- выполняешь только шаг `bind_service_team`.

### 4. Живой лог

В лог выводится:

- фактический request;
- headers;
- body;
- status;
- response headers;
- response preview;
- extract-переменные;
- итоговая карточка клиента.

Есть кнопки:

- **Выделить всё**;
- **Копировать лог**;
- **Очистить лог**.

Работают `Ctrl+A`, `Ctrl+C`, в том числе на русской раскладке.

### 5. Подкапотные запросы

Можно выбрать шаг из YAML, посмотреть и изменить:

- method;
- URL;
- headers;
- body.

Правки можно:

- сохранить как временный override;
- выполнить один выбранный запрос;
- сохранить обратно в YAML;
- скопировать как cURL.

### 6. История клиентов

В правой части есть вкладка **История клиентов**.
После успешного полного цикла туда попадает:

- время;
- ФИО;
- MDM;
- телефон;
- пакет услуг.

Можно скопировать выбранную карточку.

## Запуск из исходников

```bat
python -m pip install -r requirements.txt
python tdfg_data_factory.py
```

## Сборка exe

```bat
build_exe.bat
```

Готовый exe появится тут:

```text
dist\TDFG_Data_Factory.exe
```

## Как обслуживать

Основная настройка лежит в файле:

```text
tdfg_create_client.yaml
```

В нём можно менять без пересборки exe:

- URL контуров;
- headers;
- тела запросов;
- JSONPath для извлечения переменных из ответа;
- список шагов.

Частые места для правки:

```yaml
variables:
  base_tdfg_url: "..."
  sofk_mock_url: "..."
```

```yaml
extract:
  mdm_client: "$.tasks[0].data.partyUid"
```

Если MDM начнёт приходить в другом месте ответа, меняешь только `extract`.

## Логи

После каждого запуска создаётся папка:

```text
tdfg_logs/run_YYYYMMDD_HHMMSS/
```

Внутри:

```text
request_*.json
response_*.json
run_log.jsonl
final_context.json
```


## v1.2.1

- Смягчен визуальный стиль интерфейса: более спокойный фон, карточки и поля ввода.
- Переработаны границы и отступы блоков, чтобы элементы не наезжали друг на друга на разных размерах окна.
- Сгенерированные данные клиента теперь выводятся одной адаптивной колонкой.
